
Figma UI Design Screens

Introduction

Figma is a collaborative design tool used to create user interfaces, wireframes, and prototypes.

For this assignment, I explored Figma and created two basic screens for a university student portal.

1. Login Screen

The login screen provides an interface where students can enter their login credentials to access the student portal.

Figma Link: [https://www.figma.com/design/2QIgAhogk7VSbPH5jUpd05/HCI-week-1-Student-Portal-Wireframe?node-id=7-29&t=0UQ37kGHOLjidkp2-1]

2. Student Dashboard

The student dashboard provides an overview of important student information.

The design includes:

- Welcome message
- Student statistics cards
- Course information
- Bottom navigation

Figma Link: [https://www.figma.com/design/2QIgAhogk7VSbPH5jUpd05/HCI-week-1-Student-Portal-Wireframe?node-id=17-90&t=0UQ37kGHOLjidkp2-1]

Tools Used

- Figma
- Frames and shapes
- Text and layout elements
- Basic interface design tools

Conclusion

Creating these screens helped me understand the basics of user interface design and how to organize information in a clear and user-friendly way.
