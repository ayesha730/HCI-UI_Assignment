Learning Outcomes – HCI & UX Week 1

1. What I Learned

After completing this assignment, I gained a basic understanding of Human-Computer Interaction and User Experience design.

My key learning outcomes include:

- Understanding the meaning and importance of HCI and UX.
- Learning the stages of the HCI design lifecycle.
- Exploring Figma and its interface design tools.
- Creating a login screen and a student dashboard.
- Understanding the importance of user-friendly interfaces.
- Learning how heuristic evaluation can identify potential usability concerns.
- Applying HCI principles such as consistency, feedback, accessibility, and simplicity.
- Understanding how GitHub helps organize and share project work.

2. Practical Experience

I gained practical experience by designing two basic student portal screens in Figma:

1. Login Screen
2. Student Dashboard

These designs helped me understand how interface elements can be arranged to make a digital system easier to use.

3. Challenges Faced

During this assignment, I explored different Figma tools and learned how to organize interface elements. I also learned how to create a GitHub repository and organize assignment files using folders and Markdown documents.

4. Conclusion

This assignment improved my understanding of HCI and UX fundamentals. It provided an opportunity to combine theoretical concepts with practical interface design. I also gained experience using Figma and GitHub, which are useful tools for future software design projects.
