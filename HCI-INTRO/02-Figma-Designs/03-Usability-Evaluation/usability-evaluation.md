Usability Evaluation of a University Student Portal

1. Introduction

Usability evaluation is the process of examining a website or application to understand how easily users can interact with it.

For this assignment, I used a heuristic evaluation approach to consider common usability aspects of a university student portal.

The purpose was to understand how Human-Computer Interaction principles can improve the student experience.

2. Evaluation Criteria

The following criteria were considered:

- Navigation
- Consistency
- Readability
- System feedback
- Accessibility
- Ease of learning

3. Potential Usability Issues and Recommendations

The following points are potential usability concerns identified through a general heuristic review framework. They are not confirmed defects in the live university portal.

Issue 1: Navigation Complexity

Potential concern: Students may find it difficult to locate important sections if menu labels are unclear.

Recommendation: Use simple menu labels and organize related options into meaningful categories.

Issue 2: Readability

Potential concern: Small text or crowded information may make content difficult to read.

Recommendation: Use readable font sizes, clear headings, and appropriate spacing.

Issue 3: Color Contrast

Potential concern: Insufficient contrast between text and background can reduce readability.

Recommendation: Use accessible color combinations with sufficient contrast.

Issue 4: System Feedback

Potential concern: Unclear error messages may make it difficult for students to understand what went wrong.

Recommendation: Provide clear error messages and helpful instructions.

Issue 5: Dashboard Organization

Potential concern: Displaying too much information together may make the interface confusing.

Recommendation: Organize important information into separate sections and maintain a clean layout.

4. HCI Principles Applied

Visibility of System Status

The system should clearly communicate its current status and provide feedback after user actions.

Consistency

Similar interface elements should have consistent appearance and behavior.

Error Prevention and Recovery

The interface should help users avoid mistakes and provide understandable error messages.

Accessibility

The design should be usable by people with different abilities.

Simplicity

Important information should be easy to find without unnecessary complexity.

5. Suggested Improvements

- Organize navigation menus clearly.
- Improve text readability.
- Maintain sufficient color contrast.
- Provide helpful system feedback.
- Keep the dashboard organized.
- Make important features easy to access.

6. Conclusion

Usability evaluation is an important part of HCI because it helps designers understand how users interact with digital systems. This exercise helped me learn how to identify potential usability concerns and recommend improvements using basic HCI principles.
